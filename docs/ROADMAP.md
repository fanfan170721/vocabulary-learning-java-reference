# Reference roadmap

Implemented first:

- Java 11 + Maven + Swing
- local CSV content and deterministic four-choice session snapshots
- resume, wrong-only review, mastery, net-new goal progress and history
- SQLite profile records
- Free Dictionary API adapter with offline failure handling in the UI
- particle animation with skip and reduced-motion controls

Next parity slices:

- onboarding and 20/50/100/200/500-question assessment
- versioned 15-level content and multi-sense distractor rules
- achievements, queue, import/export with validation and backup
- local Windows speech adapter and richer settings
- transactional completion boundary and content-version snapshots
- richer presenters/controllers and PlantUML diagrams

Each slice should add tests before the code and be split into a complete User Story before it is considered for the course repository.
